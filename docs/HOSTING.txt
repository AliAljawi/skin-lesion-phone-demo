Phone demo: put this folder online with GitHub Pages (free, about 5 minutes)

1. On github.com, create a new PUBLIC repository (e.g. "skin-lesion-demo"), or use the group repo.
2. Add file > Upload files > drag in EVERYTHING in this folder (index.html, model.onnx, demo_config.json,
   sw.js, and the ort and samples folders) > Commit changes.
   (Web uploads accept files up to 25 MB; the biggest file here is about 12 MB.)
3. Settings > Pages > "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After a minute or two the page lives at https://<your-username>.github.io/<repo-name>/
   Open it once on your phone before class (it downloads the model, about 23 MB). After that it keeps
   working without a connection.

Test it on the laptop first: double-clicking index.html will NOT work (browsers block it from file://).
Instead, open a terminal in this folder and run:   python -m http.server 8000
then open http://localhost:8000 in Chrome.
